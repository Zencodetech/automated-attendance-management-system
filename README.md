# Automated Attendance Management System 📊

An automated data-driven desktop application engineered to streamline attendance tracking, data transformation, and reporting from raw unstructured datasets.

## 🚀 Key Features & Data Pipeline
- **Data Ingestion & Cleaning:** Extracts and processes raw student/participant log data from Microsoft Teams Excel/CSV formats.
- **Data Transformation (ETL):** Leverages **Python** and **Pandas** to clean, filter, and format unstructured chronological log records into structured, high-integrity attendance views.
- **Analytics Dashboard:** Built an intuitive desktop GUI using **Tkinter** to display analytical reports, complete with visual tabular insights and charts.
- **Automated Report Generation:** Exports processed data pipelines into clean, production-ready reports supporting PDF, CSV, and plain text formats.

## 🛠️ Tech Stack
- **Programming Language:** Python (100%)
- **Data Libraries:** Pandas, NumPy
- **GUI Framework:** Tkinter
- **File Utilities:** OS, CSV, OpenPyXL
